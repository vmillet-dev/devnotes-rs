# Settings

Theme, language and density, the editor, how the window behaves, global variables, shortcuts and security.

*File → Preferences…* opens four pages. The theme and the density show while you choose; nothing is saved before *Apply* or *OK*.

## General

**The general settings**

| Group | Settings |
| --- | --- |
| **Appearance** | the language (French or English), the theme (System, Dark, Light), the density (Comfortable, Compact) |
| **Cards** | how many lines of a note a card previews |
| **Editor** | the default note type, indenting with Tab, line wrapping in code |
| **Calculation** | the decimals (up to fourteen), the number format and the date format of calculation sheets |
| **Behaviour** | start with the system, minimise and close to the system tray |
| **Palette** | pinned notes first in the palette |
| **Notifications** | acknowledge each copy, announce updates |

The *Compact* density tightens the spacing, never the text. Without a system tray, the window minimises and closes normally: DevNotes refuses to hide where nothing could call it back.

## Variables

The default values of your snippets’ fields, valid for every note: a `host` variable is offered to every `{{host}}`. What is typed on a note comes first. A name is limited to letters, digits, hyphens and underscores.

## Shortcuts

The three global shortcuts, the canvas ones and the areas one. See [Quick paste and shortcuts](paste.md).

## Security

- **Passphrase**: change it, for the next launch.
- **Backup copies**: copy the library at launch, and restore a copy.

Both are detailed in [Security and backups](safety.md).

## What each library remembers

The preferences above apply to the application. Each library also remembers its own display choices, such as the *List* or *Board* view, the sort, or the API client’s active environment.
