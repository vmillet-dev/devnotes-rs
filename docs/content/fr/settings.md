# Préférences

Le thème, la langue et la densité, l’éditeur, le comportement de la fenêtre, les variables globales, les raccourcis et la sécurité.

*Fichier → Préférences…* ouvre quatre pages. Le thème et la densité se montrent pendant que vous choisissez ; rien n’est enregistré avant *Appliquer* ou *OK*.

## Général

**Les réglages généraux**

| Groupe | Réglages |
| --- | --- |
| **Apparence** | la langue (français ou anglais), le thème (Système, Sombre, Clair), la densité (Confortable, Compacte) |
| **Cartes** | combien de lignes d’une note une carte aperçoit |
| **Éditeur** | le type de note par défaut, l’indentation avec Tab, le retour à la ligne dans le code |
| **Calcul** | les décimales (jusqu’à quatorze), le format des nombres et celui des dates des feuilles de calcul |
| **Comportement** | démarrer avec le système, réduire et fermer dans la barre système |
| **Palette** | les notes épinglées en premier dans la palette |
| **Notifications** | accuser chaque copie, signaler les mises à jour |

La densité *Compacte* resserre les espacements, jamais le texte. Sans barre système, la fenêtre se réduit et se ferme normalement : DevNotes refuse de se cacher là où plus rien ne pourrait la rappeler.

## Variables

Les valeurs par défaut des champs de vos snippets, valables pour toutes les notes : une variable `host` est proposée à chaque `{{host}}`. Ce qui est saisi sur une note passe devant. Un nom se limite aux lettres, chiffres, tirets et soulignés.

## Raccourcis

Les trois raccourcis globaux, ceux du canevas et celui des zones. Voir [Collage rapide et raccourcis](paste.md).

## Sécurité

- **Phrase de passe** : la changer, pour le prochain lancement.
- **Copies de sauvegarde** : copier la bibliothèque au lancement, et restaurer une copie.

Les deux sont détaillés dans [Sécurité et sauvegardes](safety.md).

## Ce que chaque bibliothèque retient

Les préférences ci-dessus valent pour l’application. Chaque bibliothèque retient en plus ses propres choix d’affichage, comme la vue *Liste* ou *Tableau*, le tri, ou l’environnement actif du client API.
