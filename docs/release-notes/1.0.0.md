# 1.0.0, in short

The bullets below open the 1.0.0 section of `CHANGELOG.md` (`scripts/release-notes.mjs`), under
« 📌 In short »: what the pull requests alone cannot say. The gaps are those of the migration
plan, § 5.3, that a person can see.

- **A native application.** DevNotes is now one Rust program drawing its own window: no
  browser engine inside, no WebView2 to install on Windows, no WebKitGTK on Linux. It holds the
  open library in memory to search, sort and draw it without reading the disk again, and every
  screen keeps its look and its behaviour.
- **New packages.** Windows: an installer for you alone, without administrator rights (no more
  `.msi`). Linux: AppImage, `.deb` and `.rpm`. The installer and the AppImage update themselves,
  signed and checked as before. The libraries of an earlier version open as they are.
- **What looks different:** emoji in your notes are drawn in one colour; the date picker and
  the tooltips are drawn by the application; there is no spell checker; Mermaid diagrams are
  drawn by a native renderer, close to Mermaid's but not identical; code colouring splits some
  tokens differently; images other than PNG, JPEG, GIF, WebP, BMP and ICO open with your
  system's viewer, and an animated GIF shows its first frame.
- **On a Wayland session without XWayland** (rare: DevNotes uses X11 whenever it is there), the
  window's position is not restored, closing to the tray minimises, a file cannot be dropped
  from the file manager, and HTML pasted into a Note keeps its text only.
