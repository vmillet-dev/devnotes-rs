Le banc d’essai

  • Version : l’application egui de dev/0.27.0, profil com.devnotes.app.dev ou --profile <dossier>.
  • Bibliothèques : « Recette », phrase recette-devnotes-2026 (devient recette-devnotes-2027 après la section SEC) ; « Recette 2 », recette-deux-2026 ; « Recette 3 », jetable, recette-trois-2026.
  • Fichiers : recette/donnees/, décrits dans son README.md. Un clic sur une valeur de la colonne « Données » la copie.
  • Réseau : httpbin.org, postman-echo.com, countries.trevorblades.com, badssl.com. Windows, interface en français, clavier AZERTY.

Comment noter

  • OK : l’attendu est là, entièrement.
  • KO : écrire ce qui s’est passé dans le commentaire ; c’est ce que je relirai pour ouvrir les tickets.
  • Bloqué : le cas ne se déroule pas (prérequis manquant, service tiers en panne) ; dire pourquoi.
  • N/A : sans objet sur ce poste. Recliquer un statut l’enlève.
  • L’ordre des sections est l’ordre conseillé ; dans une section, certains cas s’appuient sur le précédent. P1 marque les parcours critiques, à passer en premier si le temps manque.
