{{app}} garde vos snippets, vos notes et vos listes à portée de clavier. Tout reste sur cette machine, chiffré ; rien ne part sur le réseau.

## Où sont les choses
- **Notes**, **Outils** et **HTTP** : les trois zones, sur le côté (Ctrl+1, Ctrl+2, Ctrl+3).
- Les cartes se rangent seules : épinglées, aujourd’hui, cette semaine, plus ancien. La vue **Tableau**, en haut, montre les dossiers comme des zones.
- Le menu **À propos** tient la prise en main et tous les raccourcis.

## Les touches qui comptent
| Touches | Pour |
| --- | --- |
| Ctrl+K | Chercher dans les notes, ou dans les outils |
| Ctrl+N · Ctrl+Maj+N | Un snippet · une Note |
| Entrée · C · P | Ouvrir · copier · épingler la carte |
| Ctrl+Alt+P | Coller une note depuis n’importe quelle application |

Ces exemples sont faits pour être modifiés, ou mis à la corbeille.
